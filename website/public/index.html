Nira

Personal AI, on hardware you own

An assistant that runs on your own machines. Talk to it from your phone, watch it work on a real project, and approve anything risky before it happens. Cloud APIs are optional — nothing has to leave your tailnet.

01

Quick start

One command installs it on your own machine. It picks an engine to suit your hardware, pulls a small model to start with, and every model it pulls stays local.

It goes into ~/.nira and puts nira on your PATH. Piping a URL into bash runs whatever that URL returns, so read it first: install.sh.

Already have it running? nira device pair my-phone shows a QR code — scan it with the Android app and the two are linked over your tailnet. 

$ curl -fsSL http://localhost:8080/install.sh | bash
$ nira init            # no sudo — the installer refuses root
$ nira ask "summarise the notes in ~/journal"
$ nira talk            # speak to it instead
$ nira serve
$ nira device pair my-phone   # scan from the app
02

What it is made of

Intelligence

Pick a model, or let Nira pick one that fits your hardware. It manages the catalogue of local models across providers.

Engine

The runtime — Ollama, vLLM, SGLang, llama.cpp, or a cloud API when you want one. Detected and recommended for your machine.

Agents

Multi-step work with real tools. Point one at a project directory and it edits files, runs commands and reports back.

Tools & memory

Web search, files, a code interpreter, retrieval, persistent local state, and any MCP server you care to connect.

Approvals

Anything that changes your files or runs a command can stop and ask. Answer from the desktop, or from your phone's lock screen.

Learning

Every run leaves a trace, and those traces drive improvements to prompts, routing and agent behaviour over time.

04

Install

Install the server first. The phone app talks to a desktop you have paired with, so it is not useful on its own — and says so when it has nothing to talk to.

The installer and the apk are both served from this machine — nothing here calls out to a CDN or an app store. Digests are computed when the container image is built, from the files it is about to serve; check one with sha256sum nira-android.apk after downloading.
